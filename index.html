🔒 Encapsulamento

O que é?

Esconder o estado interno do objeto e só permitir alterações através de métodos ou propriedades.

Para que serve?

Evita valores inválidos e protege os dados.

Explicação

  • _saldo é private: ninguém o altera de fora
  • Saldo só permite ler
  • Depositar valida antes de alterar
public class Conta
{
    private decimal _saldo;
    public decimal Saldo => _saldo;

    public void Depositar(decimal valor)
    {
        if (valor <= 0)
            throw new ArgumentException("Valor inválido");
        _saldo += valor;
    }
}
Experimenta: valor positivo, negativo ou zero.

🧬 Herança

O que é?

Uma classe derivada herda propriedades e métodos de uma classe base.

Como funciona?

Usa-se : na declaração. Relação do tipo «é um»: um Carro é um Veículo.

🎭 Polimorfismo

O que é?

Objetos diferentes respondem à mesma chamada de formas diferentes.

Como funciona?

  • virtual na classe base: permite redefinir
  • override na derivada: nova versão
  • O método executado depende do tipo real do objeto
Escolhe um animal.
public class Animal
{
    public virtual string EmitirSom() => "...";
}

public class Cao : Animal
{
    public override string EmitirSom() => "Au au!";
}

public class Gato : Animal
{
    public override string EmitirSom() => "Miau!";
}

Animal a = new Gato();
Console.WriteLine(a.EmitirSom()); // Miau!

🧠 Abstração

O que é?

Mostrar apenas o que é essencial e esconder os detalhes.

Porque é importante?

Simplifica o uso das classes e define regras comuns.

  • abstract class: não pode ser instanciada
  • abstract método: sem corpo, as derivadas são obrigadas a implementá-lo
Forma (abstrata)Area()
▲ ▲
Circulo
Retangulo
public abstract class Forma
{
    public abstract double Area();

    public void Mostrar() =>
        Console.WriteLine($"Área: {Area():F2}");
}

public class Circulo : Forma
{
    public double Raio { get; set; }
    public Circulo(double raio) => Raio = raio;

    public override double Area() =>
        Math.PI * Raio * Raio;
}

// var f = new Forma(); // ERRO: classe abstrata
new Circulo(2).Mostrar(); // Área: 12.57

5 · Gestão de veículos

public class Veiculo
{
    public string Marca { get; }
    public string Modelo { get; }
    private int _velocidade;              // encapsulamento
    public int Velocidade => _velocidade;

    public Veiculo(string marca, string modelo)   // construtor
    {
        Marca = marca;
        Modelo = modelo;
    }

    public void Acelerar(int kmh)
    {
        if (kmh <= 0) return;
        _velocidade += kmh;
    }

    public virtual string Descrever() =>
        $"{Marca} {Modelo} a {Velocidade} km/h";
}

Dados protegidos com private, construtor para criar o objeto e um método virtual que as derivadas podem mudar.

public class Carro : Veiculo                  // herança
{
    public Carro(string marca, string modelo)
        : base(marca, modelo) { }

    public override string Descrever() =>     // polimorfismo
        $"Carro: {base.Descrever()}";
}

public class Mota : Veiculo
{
    public Mota(string marca, string modelo)
        : base(marca, modelo) { }

    public override string Descrever() =>
        $"Mota: {base.Descrever()}";
}

Carro e Mota herdam tudo de Veiculo e redefinem apenas Descrever().

var frota = new List<Veiculo>
{
    new Carro("Toyota", "Yaris"),
    new Mota("Yamaha", "MT-07")
};

foreach (var v in frota)
{
    v.Acelerar(60);
    Console.WriteLine(v.Descrever());
}

// Carro: Toyota Yaris a 60 km/h
// Mota: Yamaha MT-07 a 60 km/h

A lista guarda Veiculo, mas cada objeto usa a sua própria versão de Descrever().
